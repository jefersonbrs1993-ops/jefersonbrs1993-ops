## 📚 Minha Jornada e Evolução

### ⏪ Semestres 1 ao 3 (Base Estrutural)
Construí a fundação da minha engenharia, focando em raciocínio lógico, arquitetura e desenvolvimento de back-end:
- **Engenharia de Software:** Orientação a Objetos, Levantamento de Requisitos de Sistemas, Modelagem com diagramas UML e aplicação prática de Design Patterns (GoF).
- **Back-end e Estruturas:** Desenvolvimento de APIs RESTful estruturadas com **Python e FastAPI**. Compreensão de estruturas de dados e baixo nível com **C**.
- **Dados:** Modelagem relacional e estruturação de bancos de dados com **SQL e SQLite**.
- **Fundamentos Web:** Construção de interfaces e lógica web utilizando **HTML, CSS, JavaScript e PHP**.
- **Versionamento:** Organização de repositórios, Git, GitHub e uso de ambientes em nuvem com GitHub Codespaces.

### 🎯 4º Semestre (Foco Atual)
O objetivo agora é expansão multidisciplinar. Minhas disciplinas e estudos estão direcionados para:
- **Desenvolvimento Full-Stack:** Integrar as interfaces visuais de forma robusta com o back-end.
- **Segurança da Informação:** Compreender vulnerabilidades, proteção de aplicações e arquitetura segura.
- **Aprofundamento em Dados:** Estruturação avançada, manipulação e segurança de informações.
- **Automação e Integrações:** Criação de bots e fluxos inteligentes utilizando APIs externas (como a do Telegram).
